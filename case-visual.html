02 / AI 商品视觉生成

让商品视觉生产
更快、更可控。

针对电商设计需求，将飞书对接图像模型 API，根据原始商品图生成设计线稿，再用参考图与大货图完成视觉替换。

项目速览
场景
电商商品视觉
工具
图像模型 API · 飞书 · 参考图
产出
线稿生成与滞销款视觉替换
状态
持续迭代中
执行

工作内容

  • 根据原始商品图生成设计线稿。
  • 结合商品参考图与大货图替换滞销款视觉表现。
  • 控制场景、姿势、模特和风格，降低视觉试错成本。
判断

产品判断

图像模型不是一次性出图工具，而是可以被拆成输入、约束、生成和筛选的视觉 Workflow。流程越清晰，结果越容易复用。
