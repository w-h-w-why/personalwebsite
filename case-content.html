02 / AI 电商内容自动化

从商品信息到标题与
种草文案的自动化生产

将商品信息、唯品会后台数据、品类搜索词与小红书趋势串联起来，用 Workflow 批量生成适配不同平台的标题，并由人工完成最终更新。

项目速览
场景
电商内容生产
工具
Coze Workflow · 飞书多维表格 · 模型 API
产出
可复制标题表与种草文案批量生成
状态
跨部门日常使用中
问题

业务问题

设计师提供的通用标题不一定适配不同电商平台。人工逐条融合商品卖点、平台品类搜索词和小红书趋势词耗时，也容易遗漏平台规避词或保持表达口径一致。

方案

产品方案

以商品信息为输入，接入唯品会后台数据与趋势词，通过 Coze Workflow 调用大模型生成标题和文案；用 Prompt 约束卖点、穿搭细节、平台规避词和输出格式，并以测试样本检查效果。

多平台适配 融合品类搜索词与平台规避词
人工把关 人工更新平台链接与最终标题
批量输出 生成可复制的标题表
落地

从个人方法到团队流程

项目与 IT 对接业务数据和接入方式，通过 OKR 会议同步进展。流程进入各部门日常使用后，支持批量生成可复制标题，平台链接仍由人工更新，避免把内容质量与发布动作混成一个自动化黑盒。

边界

AI 生成，人工做最后判断

趋势词、商品卖点和平台规则共同影响标题质量。系统负责提高初稿产能和一致性，业务人员仍对规避词、品牌口径和最终发布内容负责。
