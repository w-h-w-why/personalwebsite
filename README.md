# W.H.W. 作品集

无框架、无构建依赖的静态站。`site.config.json` 统一维护导航、标题、摘要和公开联系方式；`templates/layout.html` 是全站头部、导航、分享信息和页脚，`templates/pages/` 只放各页正文。

修改源文件后运行 `npm run build`，提交根目录 HTML；不要直接编辑生成的 HTML。运行 `npm run check` 检查生成文件是否与源文件一致。Node.js 20 或以上即可，无需 `npm install`。

GitHub Pages 工作流运行 `npm run deploy:build`，只发布 `dist/` 中的页面、样式、脚本和图片。根目录生成文件及 `_config.yml` 同时兼容现有的 Pages 根目录发布配置。

年份和自 2025 年 7 月起的任职时长在构建时生成，浏览时按上海时区更新。教育年份与真实入职月份保留为历史事实。

电话与邮箱按求职站原有用途公开，统一从配置生成可选中、可点击的 HTML；CSS 不保存个人信息。如需调整公开范围，修改共享模板/配置后重建。复制邮箱成功后给出确认，浏览器拒绝或不支持剪贴板时显示可手动选中的邮箱；禁用 JavaScript 时提供邮件联系链接。

三张案例截图采用原尺寸、逐像素一致的无损 WebP，HTML 声明尺寸并延迟加载。分享预览使用 JPEG 以兼容分享客户端；预览是否展示由平台自身的抓取与缓存规则决定。
